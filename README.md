Carbon footprint tracker
A responsive web application designed to help users calculate, track, and reduce their daily carbon emissions.
It has features like a custom bar chart that display total CO2 output across transport, food and home energy categories.
A weekly CO2 budget which u can set to any amount and inform u if u are within budget or not.
Keep track of consecutive days u log ur activity with the streak system.
View ur recent activities using activity history with categories filter.
Toggle between light mode and dark mode.
All logged activities, budgets and themes persist across browser refreshes with local storage persistance.

It is entirely built with html,css and javascript
HTML - Application structure and semantics
CSS - Custom responsive layouts (Flexbox & Grid), dark mode variables, and styled bar chart
Javascript - Dynamic UI manipulation, calculations, filter logic, and local storage persistence

To run this tracker:
Download this repository and open index.html in your desired browser and u can start using it.
